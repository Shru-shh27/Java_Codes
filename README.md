## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Java-Programs.git
```

2. Navigate to the project folder

```bash
cd Java-Programs
```

3. Compile the Java program

```bash
javac FileName.java
```

4. Run the program

```bash
java FileName
```
